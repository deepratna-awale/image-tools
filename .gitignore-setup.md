# .gitignore Configuration Summary

This document outlines the .gitignore configuration for the image-tools project.

## Project Structure

The project has three levels of .gitignore files:

1. **Root level** (`/.gitignore`) - Workspace-wide patterns
2. **Frontend** (`/frontend/.gitignore`) - Next.js/React specific patterns  
3. **Backend** (`/backend/.gitignore`) - Python/FastAPI specific patterns

## Key Patterns Ignored

### Backend (`/backend/.gitignore`)
- **Python artifacts**: `__pycache__/`, `*.pyc`, `.venv/`, etc.
- **Uploaded files**: `uploads/*` (but preserves directory structure with `.gitkeep`)
- **Environment files**: `.env`, `.env.*` (except `.env.example`)
- **Log files**: `*.log`, `logs/`
- **Model files**: `*.pth`, `*.pkl`, `*.joblib`
- **Database files**: `*.db`, `*.sqlite3`
- **Docker data**: `docker_data/`, `rabbitmq_data/`
- **Test artifacts**: `.pytest_cache/`, `coverage.xml`

### Frontend (`/frontend/.gitignore`)
- **Node.js artifacts**: `node_modules/`, `npm-debug.log*`
- **Next.js build**: `.next/`, `out/`
- **Environment files**: `.env.*` (except production configs)
- **IDE files**: `.vscode/settings.json`, `.idea/`
- **Uploaded files**: `public/uploads/`, `public/results/`
- **TypeScript build**: `*.tsbuildinfo`

### Root Level (`/.gitignore`)
- **Workspace files**: `uploads/`, `results/`, `storage/`
- **Environment files**: `.env`, `.env.*` (except `.env.example`)
- **IDE/Editor files**: `.vscode/settings.json`, `.idea/`
- **OS files**: `.DS_Store`, `Thumbs.db`
- **Docker volumes**: `docker_data/`, `rabbitmq_data/`, `redis_data/`
- **Temporary files**: `temp/`, `tmp/`, `.temp/`

## Docker Configuration

### .dockerignore Files
Both frontend and backend have `.dockerignore` files to optimize Docker builds:

- **Backend**: Excludes test files, uploads, logs, development scripts
- **Frontend**: Excludes node_modules, .next, development files, uploads

## Directory Structure Preservation

The backend uses `.gitkeep` files to preserve important directory structure:
- `uploads/.gitkeep` - Main uploads directory
- `uploads/uploads/.gitkeep` - Input images directory  
- `uploads/results/.gitkeep` - Processed images directory

## Security Considerations

- All environment files (`.env*`) are ignored except examples
- Uploaded files and results are never committed
- Database files and credentials are excluded
- Log files that might contain sensitive data are ignored

## Development Guidelines

1. **Never commit sensitive data**: Environment files, API keys, uploaded images
2. **Use .env.example**: Template for required environment variables
3. **Local testing**: Use `test_uploads/` for local testing (also ignored)
4. **Logs**: All log files are ignored; use proper logging services in production

## Adding New Patterns

When adding new file types or directories that should be ignored:

1. **Backend-specific**: Add to `/backend/.gitignore`
2. **Frontend-specific**: Add to `/frontend/.gitignore`  
3. **Project-wide**: Add to `/.gitignore`

Make sure to test that important files are still tracked by running:
```bash
git status
git check-ignore -v <file-path>
```
